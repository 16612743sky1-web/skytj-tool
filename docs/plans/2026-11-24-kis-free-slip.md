# KIS 무상전표(79*70) 수량 관리 계획서 (2026-11-24)

> 상태: **승인 대기** — 아래 "확인할 것" 답을 받은 뒤 구현

## 배경 / 목표
- 79*70 용지는 KIS가 매달 정해 주는 **무상전표 수량**만큼은 에이스아이피에서 발송하는 게 맞고,
  그 이후 건은 타 업체에서 사서 **사무실에서 로젠택배로 직접 발송**하는 편이 더 싸다.
- 에이스아이피와의 관계를 생각해 **무상수량 + 여유 5~10박스**까지는 에이스아이피로 보낸다.
- 그래서 필요한 것:
  1. 매달 **KIS 무상전표 수량 입력**
  2. **매일 / 월 누적 에이스아이피 79*70 발송 합계** 확인
  3. 월 누적이 무상수량(+여유)을 **넘으면 표시·경보**
  4. **월말정산에서 KIS 무상분 차감 후** 정산액 확인

## 1) 구글시트 스크립트 (V8)

### 새 시트 `KIS무상관리` (자동 생성, 직원이 눈으로 볼 수 있음)
- **월별 설정 표**: 월(`26.11`) · KIS 무상전표 수량(박스) · 여유(박스, 기본 10) · 이월/시작값 · 메모
- **일별 발송 기록 표**: 날짜 · 시트 · 79*70 수량 · 전체 수량 · 행수 · 방식(자동/수동) · 누적 · 상태
- 기록은 **에이스아이피 발송 메일이 성공했을 때만** `sendToAceIP` 안에서 한 줄 추가
  (노란색은 "로젠 직접발송/이미처리"도 섞여 있어 색으로는 에이스 발송분을 구분할 수 없기 때문)

### 79*70 품목 판정
- `2열`(품명)에 `79*70`, `79x70`, `79×70`, `79 * 70` 이 들어 있으면 79*70 으로 본다 (CONFIG 정규식, 바꿀 수 있음)
- 수량 = 시트의 `수량` 열 (빈칸이면 1) — 이 숫자를 **박스**로 본다

### 상태 판정 (월 누적 기준)
| 상태 | 조건 | 표시 |
|---|---|---|
| 🟢 여유 | 누적 < 무상수량 | — |
| 🟡 무상 소진, 여유 구간 | 무상수량 ≤ 누적 ≤ 무상+여유 | 로그 노랑, 카톡/메일 1회 안내 |
| 🔴 초과 | 누적 > 무상+여유 | 로그 빨강, 카톡/메일 경보 "남은 79*70 은 로젠 직접발송" |

### 메뉴 추가 (`📦 용지발송` 아래)
- `🏦 이번 달 KIS 무상전표 수량 입력` — 숫자 입력창 (여유 박스도 같이 물음)
- `📊 KIS 무상전표 현황` — 팝업: 무상수량 · 여유 · 월 누적 · 남은 수량 · **오늘 발송 대기 중인 79*70**(무색 행) · 일별 합계 표.
  "오늘 대기분까지 보내면 초과" 면 빨간 경고 → 직원이 14:50 전에 해당 행을 노란색 처리하고 로젠으로 보내면 됨
- `🔢 이번 달 이미 보낸 수량 맞추기` — 기능 도입 전(이번 달 1일~오늘) 이미 보낸 79*70 수량을 한 번 입력하는 시작값

### 자동발송 때 동작 (기본안: **표시+경보만, 자동 제외 안 함**)
- 발송은 지금처럼 그대로 나간다. 발송 직후 누적을 다시 계산해서 상태가 바뀌면 경보.
- **선택 사항**: 14:00 사전점검 트리거 — "오늘 대기분까지 보내면 초과" 면 14:50 전에 미리 카톡/메일
  (직원이 미리 빼서 로젠으로 돌릴 시간을 줌)

### 건드리지 않는 것
- C열 색 판정(`isYellowColor`/`isRedColor`/`getExcludedRows`), 열 구조 가드, 송장 감시(SECTION 15),
  송장 반영, 공휴일/휴무일 판단 — **코드 변경 없음**. `sendToAceIP` 에는 성공 직후 기록 한 줄(try/catch로 감싸서 실패해도 발송·노란색 처리에 영향 없음)만 추가.
- 기존 `발송로그` 시트 컬럼 그대로.

## 2) 월말정산 (`index.html`)
- 업로드 아래에 **"KIS 무상전표 수량(박스)"** 입력칸 (월별 값을 기기 localStorage 에 기억)
- 정산 내역에 줄 추가:
  - `79*70 에이스아이피 청구: N박스 / 금액`
  - `🏦 KIS 무상전표 차감: min(N, 무상수량) 박스 × 79*70 단가(파일1에서 계산) = - 금액`
  - `79*70 초과분(당사 부담): N - 무상수량 박스` (여유 구간 몇 박스인지 표시)
- 최종 정산액 = 기존 합계 − (기존 키핑 차감) − KIS 무상전표 차감  ← **키핑과 무상전표가 같은 건지에 따라 달라짐 (아래 확인 2)**

## 확인할 것 (사용자 답 필요)
1. 시트 `2열`(품명)에 79*70 이 정확히 어떻게 적히나요? (예: `79*70`, `KIS 79*70 용지`) — 다른 품목은 뭐가 있나요?
2. 지금 월말정산의 **"KIS 키핑재고(정기분전표 열)" 차감**과 이번 **KIS 무상전표**는 같은 건가요, 별개인가요?
   - 같다 → 키핑 차감을 "79*70 무상수량 차감"으로 바꿈
   - 별개 → 둘 다 차감 (키핑 행은 79*70 누적에서 제외할지도 결정)
3. 초과 시 동작: **표시+경보만**(기본안) vs 초과분 79*70 행을 자동발송에서 **자동 제외**
4. 여유 박스 기본값: 5 / 10 중 무엇으로? (매달 바꿀 수 있음)
5. 이번 달(26.11)에 이미 에이스로 보낸 79*70 수량을 아시나요? (모르면 월말정산 파일로 맞춤)
