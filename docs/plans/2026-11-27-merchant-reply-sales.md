# 가맹점 답장 도구 — "판매·입금 안내" 유형 추가 계획서 (2026-11-27)

> 상태: **승인됨 (2026-11-27) → 구현 완료, main 반영 전 사용자 확인 대기**

## 목표
포스용지 같은 소모품 판매 후 보내는 **세금계산서 발행용 입금계좌 안내** 카톡 문구를 버튼 몇 번으로 만든다.
사용자가 2026-11-27 보낸 실제 문구 3개를 그대로 틀로 쓴다.

## 바꿀 파일
| 파일 | 내용 |
|---|---|
| `merchant-reply/index.html` | 7번째 유형 "판매·입금" 추가, 회사 정보 설정에 **입금 계좌** 칸 추가 |
| `CLAUDE.md`, `.claude/skills/deploy-check` | 유형 목록·검증 항목 1줄씩 |

## 화면
- 유형 버튼: `판매·입금` (소모품·입금안내)
- 입력
  - 상호 (메모용, 답장에는 안 들어감)
  - 품목 빠른 선택 (자주 쓰는 것 3개 — 2026-11-27 사용자 확인, 누르면 품목·금액이 자동 입력)
    1. 포스용지(79*80) 1Box — 55,000원
    2. 포스용지(79*70) 1Box — 44,000원
    3. 포스용지(79*80) 1Box — 38,500원 (특가)
  - 품목명 직접 입력 / 수량(Box) / 입금액 (빠른 선택 금액 × 수량, 직접 수정 가능)
- 직원용 체크: 입금 확인, 세금계산서 발행, 수금방 기록
- 출력
  - 가맹점 답장 (사용자 원문 그대로):
    ```
    항상 노고가 많으십니다.
    요청하신 {품목} {수량}Box
    세금계산서 발행용 입금계좌 안내 드립니다.

    {입금 계좌 — 회사 정보 설정}
    입금액: {금액}원

    *입금자명은 반드시 대표자님 성함으로 입금 부탁드립니다. 감사합니다.
    ```
  - 업무방·수금방 메모: 날짜, 상호, 품목, 수량, 입금액, 입금 확인 O/X, 세금계산서 O/X

## 개인정보·공개 주소 처리
- **입금 계좌는 파일에 넣지 않는다.** 회수 주소·연락처와 같은 방식으로 "회사 정보 설정"에 한 번 입력하면
  그 기기에만 저장 (3줄: 은행 / 계좌번호 / 예금주). 비어 있으면 답장에 OOO.
- 38,500원 특가는 원문에 특정 가맹점 이름이 붙어 있었지만, 파일에는 **"특가"로만** 표기한다 (상호를 공개 파일에 넣지 않음).
- 상호·금액 등 입력값은 기존과 같이 저장하지 않는다.

## 확인 필요
1. ~~4번째 품목~~ → 3개가 맞음 (확인 완료).
2. 메시지 끝 "또 판매건이나 입금"이 이어지다 끊긴 것 같다. 판매·입금 건에 더 넣을 것(예: 입금 확인 후 보내는 문구, 미입금 재안내 문구)이 있는지.
3. 가격이 바뀌면 파일을 고쳐야 한다. 가격도 기기 설정에서 바꾸게 할지, 파일에 고정할지 (기본안: 파일 고정 + 금액칸 직접 수정 가능).

## 검증
- 빠른 선택 3종 → 원문과 글자 그대로 같은 답장 (계좌는 설정값), 수량 2 → 금액 2배.
- 계좌 미설정 시 OOO + "채울 것" 표시. 소스에 계좌번호 문자열 없음(grep).
- 기존 6개 유형 회귀 없음, 콘솔 오류 0, 네트워크 요청 0.
