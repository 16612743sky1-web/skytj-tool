# 카톡 '나에게 메모'로 발송 알림 받기 — 계획서 (2026-11-24)

> 상태: **승인됨 (2026-11-24)** — A 적용(V8.1), B 예약 작업은 "이상 있을 때만" 모드·평일 16:07 로 운영

## 지금 상태 (V7 점검 결과)
- `sendKakaoTalk()`은 솔라피 키가 비어 있어 **항상 건너뜀** → 카톡 경보는 지금 하나도 안 감.
- 아래 경보는 **카톡으로만** 보내게 돼 있어서, 지금은 **아무도 모르고 지나감**:

| 상황 | 위험 | 지금 |
|---|---|---|
| 발송 성공 후 **노란색 처리 실패** | 다음날 **중복발송** | 카톡만 → 무음 |
| 에이스아이피 **메일 전송 실패** | 그날 출고 누락 | 로그 ❌ + 카톡만 → 무음 |
| **공휴일 API 오류 → 자동발송 보류** | 평일인데 하루 통째 미발송 | 카톡만 → 무음 |
| 송장반영 메일검색 오류 / 첨부 파싱 실패 / 반영 불가 | 송장 누락 | 카톡만 → 무음 |
| 시트없음 / 엑셀 첨부 생성 실패 | 그날 미발송 | 로그만 → 무음 |

- 메일로도 가는 경보(0건, 송장반영 결과, 송장 미수신·반송, 열 구조 오류)는 정상.

## 방법 비교

| | A. Apps Script → 카카오 '나에게 보내기' API 직접 | B. Claude 예약 작업 → 카톡 메모(PlayMCP) |
|---|---|---|
| 속도 | **즉시** (사고 순간) | 정해진 시각 1~2회 |
| 비용 | 무료 | Claude 사용량 소모 |
| 준비 | 카카오 개발자 앱 1개 등록(10분) + 1회 로그인 | 지금 연결된 커넥터로 바로 |
| 유지 | 2달마다 토큰 자동 갱신(스크립트가 처리) | 커넥터 로그인 만료 시 재연결 |
| 받는 사람 | 등록한 본인 카톡 1명 | 본인 1명 |
| 길이 | 템플릿 텍스트 200자(+버튼 링크) | 200자 |

**추천: A(즉시 경보) + B(하루 요약) 같이 쓰기.**
A가 사고를 바로 알려 주고, B는 "오늘 발송 몇 건·KIS 누적·송장 미수신 남은 것"을 하루 한 번 정리.

## A. Apps Script 변경 (`apps-script/용지관리.gs`, KIS 무상전표 V8 작업 위에 얹음)
1. `sendKakaoTalk(text)` 내부만 교체 — 호출하는 곳 20여 군데는 그대로.
   - 카카오 토큰이 설정돼 있으면 `kapi.kakao.com/v2/api/talk/memo/default/send` 로 '나에게 보내기'
   - 없으면 기존 솔라피 경로(키 있으면) → 둘 다 없으면 건너뜀
   - 200자 넘으면 앞 190자 + "…시트 확인", 버튼 링크 = 시트 주소
2. 토큰 관리: refresh token 은 **스크립트 속성(Script Properties)** 에만 저장(코드·저장소에 안 남김).
   보낼 때마다 access token 갱신, 카카오가 새 refresh token 을 주면 자동 교체.
   갱신 실패 시 회사 메일(EMAIL_ALERT)로 "카톡 재로그인 필요" 1회 안내.
3. 메뉴 `📦 용지발송` 에 추가: `💬 카톡 알림 연결(최초 1회)` · `💬 카톡 테스트 메시지`
4. **카톡 전용 경보에 메일도 같이** 보내도록 `alert_(제목, 본문)` 헬퍼 추가 → 위 표의 무음 경보 전부 메일+카톡.
5. 알림 정리: 카톡은 사고·경보만(성공 알림은 하루 요약 B로) → 알림 피로 방지.

사용자가 할 일(한 번): developers.kakao.com 앱 생성 → 카카오 로그인 켜기 + 동의항목 '카카오톡 메시지 전송' → Redirect URI 등록 → REST API 키를 스크립트 속성에 입력 → 메뉴에서 연결. (단계별 그림 안내 제공)
