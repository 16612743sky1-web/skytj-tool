# 가맹점 답장 초안 도구 계획서 (2026-11-23)

> 상태: **승인됨 (2026-11-23) → 구현 완료, main 반영 전 사용자 확인 대기**

## 목표
가맹점 문의가 오면 **유형을 고르고 → 빈칸 몇 개를 채우면 → 카톡에 바로 붙여넣을 답장 초안**이 나오는 도구.
핸드폰(390px)에서도 1분 안에 복사까지 끝나는 것이 목표.

- 유형 6가지: **A/S 접수 · 단말기 교체 · 해지 · 수수료 · 신규문의 · 사업자변경(승계)**
- 유형마다 출력 2가지: **가맹점 답장(카톡)** + **업무방 접수 메모** (+ 직원용 체크리스트는 화면에만)
- 가맹점명·사업자번호 등 개인정보는 **어디에도 저장하지 않는다** (localStorage·파일·URL 모두).

## 화면 흐름
1. **사내 전용 배너** (접을 수 있음): 인터넷으로 아무것도 안 보냄 / 입력값 저장 안 함 / 복사한 문구는 회사 밖 공유 금지.
2. **유형 선택** — 버튼 6개 (A/S · 교체 · 해지 · 수수료 · 신규 · 승계), 2열×3줄.
3. **유형별 입력칸** — 선택한 유형에 필요한 칸만 표시.
   - **공통 접수 필수 (A/S·교체·해지)**: ① 상호 ② 주소 ③ 연락 온 번호 ④ 장비 모델명(사진 첨부 체크) ⑤ 증상 및 처리내용
     + 추가 요청사항(선택). ①~⑤ 중 빈 칸이 있으면 업무방 메모 복사 버튼에 빨간 경고
     "필수 빠짐: 주소, 모델명 사진 — 안 올리면 2차·3차 재확인, 추가 통화, 점주 불만" (그래도 복사는 가능).
   - A/S: 증상, 조치(원격/방문), 방문 예정일시
   - 교체: 증상, 기종(예: KCP-8800), 방문 예정일시, 회수 방식(방문 회수 / 택배 발송)
   - 해지: 아래 "해지 화면 상세" 참고
   - 수수료(= **카드 결제 수수료율**, 카드사가 정하고 반기마다 재산정): 문의 요지 선택
     - "수수료가 올랐어요" → 반기 재산정으로 매출 구간(영세·중소·일반)이 바뀌었을 수 있음 안내
     - "왜 이 카드만 비싸요" → 카드사별로 요율이 다름 안내
     - "낮춰 주세요" → 요율은 카드사가 정하며 대리점이 조정할 수 없음, 대신 구간 재확인은 도와드림
     - 공통 문장: 요율은 카드사가 정하고 반기마다 매출액 기준으로 다시 정해짐 / 정확한 요율은 카드사 고객센터나
       가맹점 매출 조회 서비스에서 확인 가능 / 필요하면 당사에서 확인 후 회신
4. **초안 미리보기** — 입력하는 대로 실시간 갱신. 안 채운 칸은 `OOO` 로 남고, 아래에 "채울 것: 방문일, 증상" 한 줄 표시.
5. **[복사] [모두 지우기]** 버튼. 복사 후 "복사됨" 토스트.

## 방문요청 체크리스트 (A/S·교체에서 '방문' 선택 시, 직원용)
- 오픈·마감 시간, 휴무일 확인
- 오픈 전 방문 가능 여부 (가능하면 비밀번호 확인)
- 가맹점 과실이면 비용청구 안내 후 **수금방 작성** (필수)
- 업무일지 작성
- 방문일이 **오늘**이면 노란 경고: "당일 건은 카톡만 올리지 말고 사무실에 사람 있으면 따로 말하기"

## 택배교체 체크리스트 (교체에서 '택배' 선택 시)
- 직원용: 택배교체·기존장비 회수 안내 / 송장 출력(원장 필요 시 업무방 첨부) / 과실이면 비용청구 안내 후 수금방 작성
- 가맹점 답장에 자동 포함: 새 단말기 택배 발송 안내, 기존 장비(본체·아답터·케이블) 회수 안내,
  **"교체 끝나시면 꼭 전화 한 번 주세요. 그래야 기존 장비 회수 일정을 잡을 수 있습니다."**

## 신규문의 화면 (새 유형)
- 직원용 체크: 연락 경로(인터넷 / 지인소개 / 과거 이용 가맹점 / 기타), 카드가맹 유무,
  사업자 유형(개인 / 공동대표 / 법인) → "유형 확인 후 서류 안내 문자·이메일 발송" 체크, 발신자 신분(대표자 / 가족 / 직원 / 기타)
- 설치 일정: 오픈 예정일, 인터넷·전기·인테리어 공사 완료 여부, 카운터 장비 자리 마련 여부.
  하나라도 '아직'이면 "공사·자리 완료 후 방문일정 가능" 안내가 답장에 들어가고, 다 됐으면 방문 가능 시간 칸이 열림
- 가맹점 답장: 연락 감사 → 설치 전 준비 안내
  (**"전기공사 하시는 분께 원하시는 카운터 자리에 랜선을 뽑아 달라고 해 주세요. 어려우면 빈 관이라도 남겨 주세요. 포스·CCTV가 아니라 저희 장비에 필요한 건 랜선입니다."**)
  → 카운터 장비 자리 마련 부탁 → 서류는 사업자 유형 확인 후 문자/이메일로 따로 안내 → 불필요한 방문이 없도록 준비 완료 후 일정 잡기
- **필요서류 안내 (2026-11-23 사용자 제공 원문 기준)** — 사업자 유형을 고르면 답장 끝에 서류 목록이 붙는다.
  - **개인**: ① 사업자등록증 사본 ② 대표자 주민등록증 앞/뒤(주민번호 마스킹 금지, 현주소 표기) ③ 대표자 통장 사본
    ④ 영업신고증 사본(요식업·유흥업·의료개설증·미용업·학원 등 해당 업종만) ⑤ 내부사진(업장 내부 1장, 업종 확인 가능한 내부 1장)
    ⑥ 외부사진(간판 1장 — 없으면 도로명 사진, 입구 1장) ⑦ 대표자 본인 명의 휴대폰번호(없으면 본인서명사실확인서 1장/동사무소)
    ⑧ 매장 전화번호(없으면 생략) ⑨ 이메일 주소(필수)
  - **개인 공동대표**: 개인 목록 + 각 대표자 신분증 사본, 공동대표 결제계좌 이용 신청 및 동의서, 공동대표 가맹점 가입 동의 및 위임장, 사업자용 공동인증서
  - **법인**: 법인 사업자등록증(지점이면 본점 것도) / 대표자 신분증 컬러사진 또는 스캔본 / 법인 계좌 사본(법인인감·사용인감 다르면 사용인감계)
    / 법인 인감증명서, 법인등기부등본 전부사항증명서(90일 이내, 제출용) / 주주명부(90일 이내, 법인도장 날인)
    / 외부 건물 1장, 외부 간판 1장, 내부 입구 1장, 내부 전체 1장 / 대표자 휴대폰번호
    / 사업자 공인인증서 전자서명 링크 받을 이메일 / 법인 유형별 필수 서류(직인 날인)
  - **법인 유형별 필수 서류**: 사업자번호 **가운데 2자리(4~5번째 숫자)만** 입력하면 자동 선택 (전체 번호는 입력받지 않음)
    - 81, 84~88: 주식회사 → 주주명부 / 합명·합자·유한회사 → 지분율표 또는 사원명부 (금융회사·사업보고서 제출 대상은 제외)
    - 80, 82, 89: 유치원·어린이집 → 인가증 또는 위탁계약서 / 아파트관리사무소 → 관리규약·입주자대표회의록(회의록 없으면 공문 대체)
      / 비영리법인·임의단체 → 법인등기부등본·출자자명부·정관/규약/규칙/회칙/의사록/회의록 등(등기부·출자자명부는 발급 가능한 경우만)
      → 80·82·89 는 기관 종류를 한 번 더 고르게 함
    - 82 는 "카드사에 따라 등기부등본과 정관(회칙)을 모두 받을 수 있음" 안내 추가
  - 공통 마무리: "서류는 잘림·흔들림·빛반사 없이 위에서 정면으로 찍어 이 번호로 보내 주세요 / 카드사에서 추가 서류를 요청할 수 있습니다 / 평일 기준 3일 정도 소요됩니다"
  - 서류 목록은 회사 공통 안내라 파일에 넣어도 된다 (가맹점 정보 아님)

## 사업자변경(승계) 화면 (새 유형)
- 직원용 체크: 양도인·양수인 관계(지인 / 타인 / 가족 / 기타), 포스 교육 필요 여부, 장비 그대로 승계 여부
- 답장 2개 (탭으로 전환)
  - **양도인용**: 폐업예정신고 안내 — 세무서에서 신청, "폐업하기로 한 날짜를 미리 정해 폐업신고를 해 두는 것",
    새 사업자가 사업자등록증을 받으려면 기존 사업자 폐업신고가 먼저 필요해서 승계 때 주로 한다는 설명
  - **양수인용**: 신규문의 안내와 같은 내용(설치 준비·서류 안내) + 장비를 그대로 쓰시면 계약도 이어서 승계된다는 안내
- 해지 화면에서 '폐업' 선택 후 "승계 가능"에 체크하면 → "승계 유형으로 이어서 작성" 버튼 표시 (입력값 넘겨줌)

## 해지 화면 상세 (2026-11-23 사용자 기준 반영)
해지는 "답장"보다 **통화 중 빠뜨리지 않게 챙기는 것**이 더 중요해서, 화면을 두 부분으로 나눈다.

**A. 통화 체크리스트 (답장에 안 들어감, 직원용)**
- 발신자 구분: 대표자 / 직원 / 매니저 / 담당자 + 이름
- 철수사유 (선택 + 상세 메모): 폐업(승계 없음) / 타밴 변경 / 서비스 불만 / 장비 불만 / 불필요 / 가격 불만 / 기타
- 사유별 응대 안내가 자동으로 뜸
  - 폐업 → "승계 가능 여부 꼭 묻기" + 승계 가능/불가 체크
  - 불만(서비스·장비·가격) → "개선·제품 업데이트 등으로 유지 유도" 안내
- 방문 일정: 정확한 주소 / 재통화 연락처 / 방문 가능 시간 / 시간 애매하면 비번·열쇠 확보 가능 여부 / 방문 불가 날짜·시간(이중 방문 방지)
- 반납 방식: 방문 회수 / 착불 택배(유선 단말기 1대일 때 많이 씀) / 지사 업무요청(지방)
- 해지 처리 경로: 메이트커넥트 / ASP / 기타 (가맹점별로 다름)
- 확인 체크: CMS 미납금 확인 / 카톡업무방·수금방·업무엑셀 기록
  → 체크 안 한 항목이 있으면 복사 버튼 옆에 "아직 안 챙긴 것: CMS 미납 확인" 표시

**B. 위약금 계산기**
- 기본 3년(36개월) 약정. 약정 시작일 + 해지일 → 남은 개월 자동 계산 (직접 입력도 가능)
- 위약금 = 월 임대료 × 남은 개월
- **폐업이면 부가세 미포함 금액으로 산정** (세금계산서 발행 불가). 월 임대료를 부가세 포함으로 넣으면 ÷1.1 해서 계산
- CMS 미납금이 있으면 따로 더해 합계 표시

**C. 출력 2가지 (각각 복사 버튼, 다른 유형도 동일 구조)**
1. 가맹점 답장(카톡용): 해지 접수 확인, 반납 방법, 예상 위약금(넣을지 선택), "CMS 미납 확인 후 최종 금액 안내"
2. 업무 기록 메모: 발신자·사유·응대 결과·방문 일정·반납 방식·위약금 → 카톡업무방/업무엑셀에 붙여넣기용
   (화면에서만 만들고 저장하지 않음)

## 문구 규칙 (기존 응대 스킬 `skytj-merchant-reply` 기준)
- 카톡용 평문: 이모지·굵게·표 없음, 존댓말, "사장님" 호칭.
- **교체·회수가 들어가면 비용 사전 안내 문단 자동 포함** (침수·파손·낙하 시 실비 청구 가능, 금액은 먼저 안내).
- 택배 회수 선택 시 회수 주소·연락처·보낼 것(본체·아답터·케이블) 문단 포함.
  **회수 주소·연락처·입금 계좌는 파일(GitHub)에 넣지 않는다.** 화면의 "회사 정보 설정"에 한 번 입력하면
  그 기기 브라우저에만 저장되고, 비어 있으면 문구에 `OOO` 로 나간다. (가맹점 정보가 아니라 회사 정보라 기기 저장은 허용)
- 금액 감면·분할·수리 여부 확정 같은 결정은 문구에 넣지 않는다 → "팀장 확인 후 회신드리겠습니다".
- 수수료는 **구체 요율을 도구에 넣지 않는다** (변동·가맹점별 상이) → "확인 후 정확히 안내" 형태.

## 개인정보 보호 설계
- **가맹점 입력값 저장 0**: 상호·주소·연락처·메모 등 가맹점 관련 입력은 localStorage/sessionStorage 에 쓰지 않는다.
  새로고침하면 다 비워진다. (기기에 저장되는 것은 "회사 정보 설정"과 "배너 접힘" 뿐)
- **사업자번호·TID 감지 경고**: 입력 내용에 `000-00-00000` 형태(사업자번호)나 단말기ID로 보이는 숫자열이 있으면
  빨간 안내 "답장에 사업자번호/TID 가 들어갔어요" + 초안에서 자동 마스킹(`123-**-*****`).
- 입력칸에 `autocomplete="off"` → 브라우저 자동완성 기록에도 안 남김.
- **외부 통신 0**: CDN·구글폰트·분석 스크립트 없음. `fetch`/`XMLHttpRequest`/`<form>` 없음.
  인터넷이 끊겨도 동작.
- 파일 안에 실제 가맹점 데이터 없음 (예시는 "OO마트" 같은 가짜).
