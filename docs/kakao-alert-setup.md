# 카톡 알림 연결 방법 (용지관리 Apps Script V8.1)

솔라피 없이 **카카오 '나에게 보내기'** 로 발송 사고·경보를 본인 카톡(나와의 채팅)에 바로 받는다. 무료.
처음 한 번만 10분 정도 걸린다. 키·토큰은 코드가 아니라 Apps Script **스크립트 속성**에만 저장된다.

## 1. 카카오 개발자 앱 만들기 (PC 권장)
1. https://developers.kakao.com 에 카톡 받을 본인 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
   (앱 이름 예: `스카이티제이 알림`, 회사명 입력)
2. 만든 앱 → **앱 키** 에서 **REST API 키** 를 복사해 둔다.
3. **카카오 로그인** 메뉴 → **활성화 ON** → **Redirect URI** 에 아래 주소를 그대로 등록
   `https://16612743sky1-web.github.io/skytj-tool/`
4. **카카오 로그인 → 동의항목** → **카카오톡 메시지 전송 (talk_message)** 을 **선택 동의** 로 설정
5. **앱 설정 → 플랫폼 → Web** → 사이트 도메인에 `https://docs.google.com` 등록
   (카톡 메시지의 "시트 열기" 버튼이 구글시트로 열리게)

## 2. 스크립트 붙여넣기
- 구글시트 → 확장 프로그램 → Apps Script → 기존 코드를 `용지관리_V8_붙여넣기용.gs` 로 교체 → 저장
- 시트 새로고침 → 메뉴 **📦 용지발송** 에 💬 항목 3개가 보이면 OK

## 3. 연결
1. **📦 용지발송 → 💬 카톡 알림 연결**
2. REST API 키 붙여넣기 → "카카오 로그인 열기" → 로그인 → **카카오톡 메시지 전송 동의**
3. 월말정산 페이지가 열리면 **주소창 전체**(`…?code=…`)를 복사 → 연결 창을 닫고 나오는 칸에 붙여넣기
4. 카톡 "나와의 채팅"에 `카톡 알림 연결 완료 ✅` 가 오면 끝

## 알아둘 것
- 받는 사람은 **연결한 본인 1명**. 직원 공유는 지금처럼 회사 경보메일.
- 로그인 토큰은 약 2달 유효하고 알림을 보낼 때마다 자동 연장된다. 만료되면 회사 경보메일로
  "카톡 알림 재연결 필요" 가 하루 1번 오니 3번만 다시 하면 된다.
- 같은 경보는 3시간 안에 다시 보내지 않는다 (1시간마다 도는 송장반영 오류 반복 방지).
- 정상 동작(공휴일 건너뜀, 송장반영 성공 요약)은 카톡으로 안 보낸다. 사고·경보만 온다.
- 테스트: **💬 카톡 테스트 메시지** / 끊기: **💬 카톡 알림 연결 해제**
