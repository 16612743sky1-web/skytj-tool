# 응대 기록 시트 설치 안내 (한 번만, 약 10분)

가맹점 답장 도구의 「복사 + 시트 기록」 버튼을 쓰려면 내 구글시트를 하나 만들어 연결해야 합니다.
PC에서 하는 걸 추천해요. 연결은 **기기마다** 한 번씩 합니다 (휴대폰도 쓰면 휴대폰에서도 4단계만).

## 1. 시트 만들기
1. 구글 드라이브 › 새로 만들기 › 구글 스프레드시트. 이름은 예: `가맹점 응대 기록`.
2. 공유는 하지 마세요 (본인만). 나중에 직원이 쓰면 그 사람만 편집자로 추가.

## 2. 스크립트 붙이기
1. 시트 메뉴 **확장 프로그램 › Apps Script**.
2. 왼쪽 `Code.gs` 의 기본 내용을 지우고, 저장소의 `merchant-reply/apps-script.gs` 내용을 **전부** 붙여넣기 → 저장(💾).
   (답장 도구 › 📒 응대 기록 시트 연결 › "스크립트 파일" 링크로도 열 수 있어요.)
3. 위쪽 함수 선택에서 **setup** › ▶ 실행.
   - 처음엔 "권한 검토" 창이 뜹니다 → 내 계정 선택 → "고급" › "(안전하지 않음)으로 이동" › 허용.
     (내가 만든 스크립트라 구글이 검증 안 된 앱이라고 표시하는 것뿐이에요.)
4. 시트로 돌아가면 `응대기록` · `통계` · `설정` 탭이 생기고, **설정 탭 B2 에 비밀키**가 있습니다.

## 3. 웹 앱으로 배포
1. Apps Script 오른쪽 위 **배포 › 새 배포**.
2. 톱니(유형 선택) › **웹 앱**.
3. 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자** → 배포.
4. 나오는 **웹 앱 URL** (`…/exec` 로 끝남)을 복사.

"모든 사용자"여도 비밀키가 없으면 아무것도 기록되지 않습니다.

## 4. 답장 도구에 연결
1. 가맹점 답장 도구 › **📒 응대 기록 시트 연결** 열기.
2. 웹 앱 URL, 비밀키, 담당(이름) 입력 › **이 기기에 저장** › **연결 테스트** → "연결됐어요 ✓".
3. 이제 업무방 접수 메모의 **복사 + 시트 기록**을 누르면 카톡용 메모가 복사되면서 시트에 한 줄이 쌓입니다.

## 매일 쓰는 법
- 응대 → 칸 채우기 → **복사 + 시트 기록** → 카톡 업무방에 붙여넣기. 끝.
- 메모 맨 위 **접수번호**(예: `261123-1430-K7`)가 시트 A열과 같아서, 카톡과 시트를 번호로 맞춰 볼 수 있어요.
- 내용을 고치고 다시 누르면 **같은 줄이 수정**됩니다. 다음 가맹점은 「모두 지우기」 후 작성 (상호를 바꾸면 새 번호로 들어가요).
- 처리하면 시트에서 **상태**(접수→진행→완료/보류)와 **완료일**만 바꿔 주세요. 도구가 다시 보내도 상태·완료일·비고는 덮어쓰지 않습니다.
- 시트 연결이 안 된 기기나 회사 PC에서 막히면 **시트용 한 줄 복사** → `응대기록` 맨 아래 빈 줄 A칸에 붙여넣기.

## 통계 탭
이번 달·지난 달 유형별 건수, 평균 처리 일수, 폐업 해지 중 승계 가능, 해지 사유 순위, A/S·교체 장비 모델 순위,
같은 가게 반복 문의(90일 2회 이상), 해지 월별 건수·위약금, 미완료 건, 월별 추이가 자동으로 계산됩니다.

## 문제가 생기면
| 메시지 | 할 일 |
|---|---|
| 비밀키가 맞지 않아요 | 설정 탭 B2 값을 다시 복사해 넣기 |
| 응대기록 탭이 없어요 | Apps Script 에서 setup 다시 실행 (기존 기록은 안 지워짐) |
| 시트 응답을 읽지 못했어요 | 배포 액세스 권한이 "모든 사용자"인지 확인 |
| 비밀키가 샌 것 같다 | 시트 메뉴 › 응대기록 › 비밀키 새로 만들기 → 도구에 새 키 입력 |
| 스크립트를 고쳤다 | 배포 › 배포 관리 › 수정 › 버전: 새 버전 (URL 그대로 유지) |

## 개인정보
- 시트 주소·웹 앱 URL·비밀키는 이 저장소나 공개 페이지에 절대 올리지 마세요. 기기 설정에만 둡니다.
- 주민번호·사업자번호처럼 보이는 숫자는 보내기 전에 자동으로 가려집니다.
- 위약금 계산의 원값(임대료·약정일)은 보내지 않고 결과 금액만 기록합니다.
